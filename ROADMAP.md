# VENDO — дорожная карта

## Этапы MVP (выполнено в этой итерации)

| Этап | Критерий готовности | Статус |
|---|---|---|
| 1. Исследование | Окружение проверено, риски зафиксированы | ✅ |
| 2. Проектирование | ARCHITECTURE / DATABASE / SECURITY / ROADMAP / PROJECT_STATUS | ✅ |
| 3. Фундамент | Схема + миграции, авторизация, хранилище фото, дизайн-система, тесты | ✅ |
| 4. Основной продукт | Главная, категории, поиск, объявление, кабинет, избранное, контакты | ✅ |
| 5. Управление | /admin: роли, модерация, жалобы, категории, пользователи, магазины, контент, настройки, аудит | ✅ |
| 6. Монетизация | Подписки, продвижение, реклама, статистика, задел под платежи | ✅ (без онлайн-оплаты) |
| 7. Проверка | Тесты, линтер, типы, production build, проверка в браузере (desktop + mobile) | ✅ |

## Следующие этапы

1. **Запуск в интернете** — Supabase (БД + Storage) + Vercel, домен, Resend для писем, cron для обслуживания.
2. **Юридическое** — проверка товарного знака/домена VENDO, юрист: условия, политика конфиденциальности (закон РУз «О персональных данных», локализация ПДн граждан РУз).
3. **Онлайн-оплата** — Payme / Click / Uzum Bank (см. ARCHITECTURE.md).
4. **Доверие** — подтверждение email/телефона (SMS-провайдер), 2FA для сотрудников, апелляции на решения модерации, автоматический фильтр запрещённых слов.
5. **Рост** — уведомления в Telegram-боте, сохранённые поиски, сравнение, чат внутри платформы (опционально), мобильное приложение на тех же сервисах.
6. **Недвижимость** — включить категорию `real-estate` и добавить характеристики (площадь, комнаты, этаж).
7. **Наблюдаемость** — Sentry/OpenTelemetry, алерты, nonce-CSP.

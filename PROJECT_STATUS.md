# VENDO — статус проекта

_Обновлено: 2026-10-20_

## Сделано

- Next.js 16 + TypeScript strict + Tailwind v4, дизайн-система (графит + лаймовый акцент, шрифт Manrope, токены, кнопки, поля, карточки, модальные окна, уведомления, пустые состояния, skeleton).
- PostgreSQL-схема из 30 таблиц, 3 миграции (включая RLS deny-all), индексы для поиска и фильтров.
- Справочные данные: 14 регионов / 35 городов Узбекистана, 13 корневых категорий и 41 подкатегорией с характеристиками, «Недвижимость» подготовлена и выключена, 3 тарифа магазинов, 3 тарифа продвижения, 3 рекламных места, страницы (о платформе, безопасность, правила + запрещённые товары, условия, конфиденциальность, помощь, FAQ), 7 подборок главной.
- Авторизация: регистрация, вход по email **или логину**, выход, восстановление пароля, сессии, лимиты попыток.
- **Super Admin `apex348` создан** через CLI (`npm run admin:create`); пароль хранится только как scrypt-хеш, в файлах проекта его нет.
- Публичный сайт на 3 языках (ru / uz / en): главная (поиск с автодополнением, недавние/популярные запросы, категории, рекомендуемые, новые, рядом, популярные, подборки, блоки для продавцов и магазинов), поиск и категории с серверными фильтрами (цена/валюта, город, тип, состояние, дата, характеристики категории), страница объявления (галерея, характеристики, продавец, похожие, избранное, поделиться, жалоба, безопасность, JSON-LD), магазины, профиль продавца, тарифы, справочные страницы, 404/ошибки, sitemap, robots, canonical, Open Graph.
- Размещение: 6-шаговый мастер с прогрессом, автосохранением черновика, загрузкой/сортировкой/удалением фото, выбором главного фото, характеристиками категории, предпросмотром; редактирование; снятие с публикации; «продано / сдано / услуга недоступна»; повторная публикация; удаление.
- Кабинет: обзор, мои объявления по статусам, избранное, статистика (просмотры, показы телефона, звонки, Telegram, избранное по дням), продвижение, магазин, подписка, уведомления, настройки профиля и пароля.
- Админ-панель `/admin`: обзор, модерация (одобрить / отклонить с причиной / снять / заблокировать, история статусов), жалобы, пользователи (поиск, блокировка, роли), категории (дерево, создание, редактирование, вложенность, порядок, иконки, SEO, характеристики и варианты, безопасное удаление с переносом), магазины (статус, отметка проверки), монетизация (тарифы, лимиты, заявки и ручная активация после оплаты), реклама (места, кампании, расписание, таргет, показы/клики), контент (страницы, FAQ, подборки), настройки (премодерация, лимиты, контакты поддержки), журнал действий.

## Известные ограничения

- Онлайн-оплата не подключена (по ТЗ): платные функции активируются вручную после подтверждения оплаты.
- Письма: локально ссылка восстановления пароля печатается в лог сервера; в продакшене нужен Resend (`MAIL_DRIVER=resend`).
- Админ-панель только на русском языке.
- Встроенная БД (PGlite) — один процесс: перед CLI-командами остановите сервер. Для продакшена — внешний PostgreSQL.
- `STORAGE_DRIVER=local` не подходит для Vercel (нет постоянного диска) — там используйте `supabase`.
- Нет подтверждения email/телефона, 2FA и строгой CSP (см. ROADMAP.md).
- В локальной БД есть 10 тестовых объявлений «[ТЕСТ]» (`npm run db:demo:clear` удаляет их) и черновик, созданный при проверке мастера от имени `apex348` (удаляется в «Мои объявления»).

## Что нужно сделать вам

1. Перед публичным запуском проверить: свободен ли товарный знак «VENDO» в Узбекистане (Агентство по интеллектуальной собственности) и странах СНГ, домены (`vendo.uz` и др.), название юрлица. **Ничего из этого не проверялось.**
2. Отдать юристу тексты «Условия использования» и «Политика конфиденциальности» (сейчас это черновики), учесть требование о хранении ПДн граждан РУз на серверах в Узбекистане.
3. Создать аккаунты (бесплатные тарифы): Supabase (БД + Storage), Vercel (хостинг), Resend (почта); при подключении оплаты — договор с Payme / Click / Uzum.
4. Задать цены тарифов в `/admin/monetization` (сейчас стоят условные значения) и реквизиты для оплаты в `/admin/settings`.
5. Рекомендуется сменить пароль администратора, так как он передавался в чате: `ADMIN_USERNAME=apex348 ADMIN_PASSWORD=<новый> npm run admin:create`.

## Бесплатный запуск и будущие расходы

Лимиты бесплатных тарифов меняются — сверьте на сайтах сервисов перед запуском. Ориентиры по моим данным (могут быть устаревшими):

- Supabase Free: небольшая БД (~500 МБ) и хранилище (~1 ГБ), проект «засыпает» при неактивности, без бэкапов с восстановлением → при росте Pro (~$25/мес).
- Vercel Hobby: только некоммерческое использование по условиям → для коммерческого запуска Pro (~$20/мес за участника) или свой VPS (~$5–20/мес).
- Resend Free: ограниченное число писем в день/месяц.
- Рост расходов: хранение фото (основной объём), трафик, бэкапы, SMS-подтверждение, платёжный провайдер (комиссия с платежей).

Бесплатные тарифы не рассчитаны на миллионы пользователей.
